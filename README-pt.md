# MyMoney

**Primeira versão do projeto** — Em desenvolvimento.

Este projeto é uma plataforma para gestão de finanças, permitindo que os usuários registrem ciclos de cobrança, créditos e débitos. 

### Status do Projeto:
- **Versão atual**: 0.1 (em desenvolvimento)
- **Funcionalidades atuais**:
  - Registro de ciclos de cobrança
  - Cadastrar, deletar e alterar créditos e débitos

### O que está por vir:
- Melhorias na interface (atualmente está disponível apenas para desktop)
- Novas funcionalidades de gerenciamento de usuários
