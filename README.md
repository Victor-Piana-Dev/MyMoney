# MyMoney

**First version of the project** — In development.

This project is a financial management platform that allows users to record billing cycles, credits, and debts.

### Project Status:
- **Current version**: 0.1 (in development)

- **Current features**:

- Billing cycle registration
- Create, delete, and update credits and debts

### What's coming next:
UI improvements (currently available only for desktop)

New user management features
